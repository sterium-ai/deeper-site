# deeper-site

**https://play.steriumai.dev** — the free browser demo of **Deeper** by Sterium AI, plus its privacy policy
(`privacy.html`) and press kit (`press.html`). Served with GitHub Pages. The main site is https://steriumai.dev.

`index.html` is the single-file demo build from the game repo (`npm run build:demo`, then copy `dist/index.html`).
